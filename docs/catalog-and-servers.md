# Каталоги и избранные серверы

Каталог автоматически объединяет результаты Modrinth и CurseForge без переключателя источника. Страница содержит до 12 результатов каждого источника; при недоступности одного сервиса другой продолжает работать. CurseForge поддерживает моды, шейдеры и ресурспаки; импорт ZIP-сборок CurseForge пока не реализован. Сборки Modrinth доступны как прежде.

Для CurseForge укажите выданный этому приложению API-ключ в **Настройки → Загрузки → CurseForge**. Он хранится локально в `state.json`; альтернативно можно задать переменную окружения `CURSEFORGE_API_KEY`, которая имеет приоритет. Ключ передаётся только API CurseForge, в заголовке `x-api-key`. Документация и получение доступа: https://docs.curseforge.com/rest-api/ .

Фильтры учитывают версию Minecraft и загрузчик. Установка проверяет SHA-1 и разрешённый CDN, загружает обязательные зависимости. Запрет автора на распространение и отсутствие downloadUrl возвращают понятную ошибку без обхода ограничений. В локальном списке идентификаторы CurseForge имеют префикс `cf-`. Существующий поиск обновлений через Modrinth не является поиском обновлений CurseForge.

На главном экране справа показаны до трёх избранных серверов одновременно. «＋» добавляет сервер, «×» удаляет, адрес или «▶» запускает выбранный профиль с подключением к серверу. Онлайн и PNG-иконка получаются из Minecraft server status; если сервер не отдаёт иконку, отображается первая буква названия. При отсутствии ответа подключение всё равно можно попробовать. Список сохраняется в данных лаунчера; ранее сохранённые записи не удаляются автоматически.

Проверки: `node tools/build.cjs test`, `node tools/ui-smoke.cjs`, `node tools/servers-catalog-smoke.cjs`. Скриншот с демонстрационными серверами: `node tools/server-preview.cjs`. Последние три команды требуют Playwright (или путь в `PLAYWRIGHT_MODULE`) и Microsoft Edge. Сетевой поиск и загрузка CurseForge требуют действующего API-ключа и не проверяются тестовыми данными интерфейса.

В 0.9.1 после неудачного прямого запроса публичный адрес сервера проверяется через [mcsrvstat.us](https://api.mcsrvstat.us/). Онлайн, число игроков и иконка отображаются только при подтверждённом ответе; подсказка у статуса указывает источник и задержку кэша до 5 минут. Локальные адреса остаются на прямой проверке. На открытом главном экране онлайн обновляется раз в минуту, после ошибки — через 15 секунд. Проверка виджета без браузера: `node tools/server-widget-test.cjs`.
