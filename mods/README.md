# KYRO Panels

Встроенный в KYRO Launcher клиентский HUD для **Fabric 1.21.11, Windows 10/11**.
Установка: главное меню → KYRO Panels → Установить в профиль. Fabric API поставляется вместе с модом; существующий Fabric API не заменяется.

- Правый Shift — открыть редактор (клавишу можно переназначить в управлении Minecraft).
- Переключатели «Инфо: ВКЛ/ВЫКЛ» и «Музыка: ВКЛ/ВЫКЛ» сразу скрывают панели и сохраняют выбор. Сброс позиций не включает отключённые панели.
- Перетащить панели мышью; отпустить для сохранения. Esc / Готово также сохраняют.
- Позиции и видимость хранятся в `config/kyro-panels.json` выбранного профиля.
- Музыка поступает из текущей системной медиасессии Windows: браузер или приложение. Название, исполнитель, прогресс, пауза и переключение зависят от возможностей источника.
- Кнопки плеера работают в редакторе. Во время игры панели закреплены.
- Удалить / отключить HUD можно в менеджере модов. Музыкальный помощник завершает работу вместе с Minecraft; сетевых подключений не создаёт.

## Сборка

Java 21, Gradle 9.2.1, Rust MSVC.
`node tools/build-hud.cjs` собирает мод и помощник и копирует их в ресурсы лаунчера.
`node tools/build.cjs test` проверяет лаунчер, метаданные ресурсов, установку, совместимость, повторную установку и сохранность существующих файлов.

Fabric API распространяется по Apache-2.0: https://github.com/FabricMC/fabric . Собственный код KYRO — лицензия корневого проекта.
