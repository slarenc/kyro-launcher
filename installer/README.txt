KyroLauncher

Установщик создаёт ярлык KyroLauncher на рабочем столе и в меню «Пуск».
По умолчанию программа устанавливается для текущего пользователя в
%LOCALAPPDATA%\Programs\KyroLauncher без прав администратора.

Настройки, аккаунты, миры и моды по умолчанию сохраняются отдельно:
%LOCALAPPDATA%\KyroLauncher. Удаление программы не удаляет игровые данные.
Для переноса данных используйте настройки и папки профилей лаунчера.

Для работы Discord Rich Presence запустите настольное приложение Discord.
Minecraft и Java загружаются отдельно при подготовке игры.

https://github.com/slarenc/kyro-launcher

Интерфейс Tauri требует Microsoft Edge WebView2 Runtime.
